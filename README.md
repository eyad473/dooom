# بوت تعلم الإنجليزي (A2 → immersion)

نفس خطوات "المساعد الشخصي" اللي عملناه، بس مشروع منفصل.
يستخدم **Gemini API من Google** (مجاني بالكامل، بدون بطاقة ائتمان) بدل Anthropic.

## الحصول على مفتاح Gemini المجاني (المزود الرئيسي)
1. افتح **aistudio.google.com**
2. سجل دخول بحساب Google
3. اضغط "Get API key" → "Create API key"
4. انسخ المفتاح

## الحصول على مفتاح Cohere المجاني (احتياطي تلقائي)
لو صار خلل بـ Gemini (تعطل مؤقت، تجاوز الحد المجاني...)، الكود بيحول تلقائيًا لـ Cohere من غير ما تحس.
1. افتح **dashboard.cohere.com**
2. سجل حساب مجاني
3. من القائمة الجانبية: **API Keys** → انسخ الـ Trial key الجاهز تلقائيًا

## النشر
```bash
wrangler login
wrangler d1 create english-coach-db
# انسخ database_id لملف wrangler.toml

wrangler d1 execute english-coach-db --file=./schema.sql --remote
wrangler d1 execute english-coach-db --file=./seed.sql --remote

wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put GEMINI_API_KEY
wrangler secret put COHERE_API_KEY
wrangler secret put WEBHOOK_SECRET

wrangler deploy
```

اضبط الـ webhook (نفس الطريقة السابقة):
```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://english-coach-bot.YOUR-SUBDOMAIN.workers.dev/webhook/<WEBHOOK_SECRET>
```

| أي سؤال عربي عن كلمة/قاعدة | يجاوبك بالعربي بإيجاز |

## الميزات المتقدمة الجديدة

**1. تحليل الأخطاء وبروفايل الضعف** — `/weakness` `/focus`
كل تصحيح (بالمحادثة الحرة أو الكتابة) بيتصنف تلقائيًا لفئة (أزمنة، حروف جر، أدوات تعريف...) ويتخزن. `/weakness` يوريك أكتر نقاطك تكرارًا، و`/focus` يولّد درس مصغّر + تمارين مركّزة على أضعف نقطة.

**2. اختبار تحديد مستوى تكيّفي (Adaptive Testing)**
`/leveltest` هلأ بيصعّب أو يسهّل كل سؤال حسب إجابتك السابقة (زي TOEFL الحقيقي) — نتيجة أدق بأسئلة أقل (~10 بدل 20).

**3. بحث دلالي بمكتبة الفيديوهات** — `/find (وصف)`
تكتب "بدي شي عن طلب أكل بمطعم" بلغة طبيعية، والبوت يفهم المعنى (مو بس الكلمات) عبر Cloudflare Vectorize ويطلعلك أنسب فيديو.
⚠️ **خطوة نشر إضافية مطلوبة:** بعد أول نشر، افتح مرة وحدة:
```
https://<رابط-الووركر>/admin/index/<WEBHOOK_SECRET>
```
هاد بيفهرس كل الفيديوهات بـ Vectorize (يوم واحد بس، وكرر لو ضفت فيديوهات جديدة لاحقًا).
لازم كمان تنشئ الـ index قبل هيك:
```bash
wrangler vectorize create content-index --dimensions=768 --metric=cosine
```

**4. ذاكرة طويلة المدى (RAG-lite)**
نصوص القراءة الجديدة بتُبنى بحيث تدسّ نقطة ضعفك الحالية بقصد ضمن القصة — تعزيز تصحيح مستمر بدل تكرار عشوائي.

**5. منهج أسبوعي تلقائي** — `/plan`
البوت يبني لك خطة 7 أيام فعلية حسب مستواك وأخطائك (يوم قواعد مركّز على ضعفك، يوم استماع، يوم كتابة...) ويرسلها تلقائيًا كل صباح.

**6. انغماس تدريجي**
نسبة العربي بالردود (المحادثة الحرة والـ roleplay) بتقل تلقائيًا كل ما يرتفع مستواك — A1/A2 عربي كتير للشرح، C1/C2 إنجليزي شبه كامل.

## اختبار تحديد المستوى والقائمة التفاعلية

- `/start` أو `/menu` بيوريك قائمة أزرار — كل شي بالضغط، ما تحتاج تحفظ أوامر (زي كشف المخيم).
- `/leveltest` اختبار شامل من 3 أقسام:
  1. **قواعد** (12 سؤال متدرج A1 → C2)
  2. **مفردات** (6 أسئلة معنى كلمة، متدرجة الصعوبة)
  3. **فهم قرائي** (فقرة قصيرة + سؤالين)
  - بعد الأسئلة، بيطلب منك تكتب 2-3 جمل بالإنجليزي عن نفسك — الذكاء الاصطناعي يحلل مستوى كتابتك ويدمجه مع نتيجة الأسئلة للوصول لمستوى نهائي أدق.
  - بالنهاية، مستواك ينضبط تلقائيًا بالبوت.

## سلسلة الأيام المتواصلة (Streak)
- كل تفاعل مع البوت (أمر أو رسالة) بيحدّث سلسلة أيامك تلقائيًا.
- لو فاتك يوم كامل بدون تفاعل، السلسلة بترجع لـ 1.
- تشوفها بـ `/stats`، وإذا ما تفاعلت اليوم وعندك سلسلة قايمة، بيجيك تنبيه بالصباح يذكّرك قبل ما تنكسر.
- هاي أقوى أداة نفسية للاستمرارية — الطلاقة بتجي من التكرار اليومي مش من جلسات مكثفة متقطعة.

## المهارات المغطاة بالكامل
- **مفردات:** `/new` `/review` — تكرار متباعد SM2 + نطق صوتي تلقائي
- **استماع:** `/videos` `/todayvideo` — مكتبة مصنّفة A1-C2
- **قراءة:** `/reading` — نصوص مولّدة حسب مستواك مع أسئلة فهم
- **كتابة:** `/write` — تصحيح فوري + نسخة محسّنة
- **تحدث:** `/speak` — تفريغ صوتي (Whisper) + تحليل لغوي
- **محادثة تفاعلية:** `/roleplay` — 4 سيناريوهات واقعية عامة (عمل/مطعم/سفر/تسوق)
- **نطق:** `/pronounce` — تسمع النطق الصحيح لأي كلمة/جملة فورًا

## ملاحظة عن ميزتي التحدث والنطق (Cloudflare Workers AI)
- تحتاج تفعيل **Workers AI** بحسابك بـ Cloudflare (مجاني بحدود استخدام معقولة). البايندنج `[ai]` بملف `wrangler.toml` كافي.
- التفريغ الصوتي (Whisper) بيشتغل أفضل بتسجيل واضح وهادئ.
- **مهم:** اسم موديل النطق الصوتي `@cf/myshell-ai/melotts` بملف `worker.js` ممكن يتغيّر مع تحديثات Cloudflare — تأكد منه بتوثيق Workers AI (developers.cloudflare.com/workers-ai/models) قبل النشر، وعدّله إذا لزم.
- التقييم بميزة التحدث بيركز على المحتوى اللغوي (قواعد/مفردات) مو على جودة النطق الصوتي نفسها.

## مكتبة الفيديوهات
- كل مستوى (A1 لـ C2) فيه قنوات تعليمية + مسلسلات/سكيتشات + رسوم متحركة (A1-A2) + مقاطع ومحاضرات + محادثات واقعية.
- الروابط هي روابط **بحث يوتيوب** (مو فيديو محدد) عشان ما تنكسر لو انحذف فيديو معيّن — دايمًا بترجعلك نتائج حديثة وذات صلة.
- كل صباح البوت بيبعتلك اقتراح فيديو تلقائي حسب مستواك، بالإضافة لتذكير الكلمات.
- تقدر تضيف فيديوهات/قنوات إضافية بأي وقت مباشرة بجدول `content` بقاعدة البيانات.

## كيف يشتغل نظام المراجعة (SM2)
- كل كلمة إلها: سهولة (ease) + فترة (interval) + عدد مرات التكرار.
- لما تقيّم كلمة، الفترة القادمة تتحسب تلقائيًا (يوم، 6 أيام، وبعدين تتضاعف حسب سهولتها).
- كل صباح (8:00 بتوقيت غزة) البوت يبعتلك تذكير: إما "عندك كلمات للمراجعة" أو "تعلم كلمة جديدة".

## تعديلات مقترحة لاحقًا
- تحديد وقت التذكير الصباحي حسب رغبتك (عدّل قيمة الكرون بـ `wrangler.toml`).
- Gemini مجاني بحدود سخية (15 طلب/دقيقة تقريبًا للموديل المجاني)، فما في داعي تفكر بالتكلفة. لو حبيت موديل أسرع، بدّل `gemini-2.0-flash` بـ `gemini-2.0-flash-lite` بملف `worker.js`.
- ممكن نضيف وضع "محادثة صوتية" لاحقًا لو حبيت.
